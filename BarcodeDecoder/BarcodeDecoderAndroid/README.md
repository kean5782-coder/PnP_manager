# BarcodeDecoder Android App

Нативное Android-приложение для динамического сканирования штрихкодов компонентов камерой смартфона и их мгновенной расшифровки.

## Возможности
- **Потоковое сканирование через CameraX + Google ML Kit:** Каждые 200 мс сканирует видеопоток.
- **Интерактивный выбор (Tap-to-Select):** Отрисовка светящихся рамок вокруг всех найденных кодов. Чтобы расшифровать код (даже если он 1 в кадре), пользователь нажимает пальцем на нужный штрихкод.
- **Поиск в браузере:** Быстрый переход в поисковую систему для поиска даташитов и информации по распознанному Part Number или нераспознанному коду. Приложение работает автономно и не требует прямого доступа в интернет.
- **Полная база правил расшифровки:** Все производители конденсаторов и резисторов (включая российские Р1-12 и Р1-16) из `BarcodeDecoder_1.1.py`.
- **Фонарик, ручной ввод, копирование результата.**

## Сборка
```powershell
.\gradlew.bat assembleDebug
```
APK файл будет в `app/build/outputs/apk/debug/app-debug.apk`.
